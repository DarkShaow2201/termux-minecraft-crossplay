UPLOAD YOUR WORLD HERE

The server's default world folder is:

  worlds/world/

Put the extracted Minecraft world in that folder. The file below must exist:

  worlds/world/level.dat

Stop the server before replacing a world. Do not upload only a zip file and do
not add an extra nested folder. The Nether and End folders use these names:

  worlds/world_nether/
  worlds/world_the_end/
